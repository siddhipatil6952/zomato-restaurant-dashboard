# Dining Through Data — Zomato Dashboard

## Files
- `app.py`: Streamlit dashboard
- `requirements.txt`: Python dependencies
- `zomatocleaned.csv`: Your cleaned dataset (add this file beside app.py in the GitHub repository)

## Run locally
1. Install Python.
2. Open a terminal in this folder.
3. Run: `pip install -r requirements.txt`
4. Run: `streamlit run app.py`

If the CSV is not present in the project folder, you can upload it using the sidebar.

## Deploy online
Upload `app.py`, `requirements.txt`, and `zomatocleaned.csv` to a GitHub repository. In Streamlit Community Cloud, create an app using that repository and select `app.py` as the main file.
